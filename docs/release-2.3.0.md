# 2.3.0：独立文案检查与客户端预算

以公开2.2.0为基线增加copy-polish与codex-context-budget，共19项工具、17条workflow。只提取已冻结维护源码，三种主体文档与页面字段可独立核对，不要求作者的Research、Knowledge、个人网站、AWS或meta。旧17项源与许可不覆盖；registry旧行保留，原game-research/knowledge/game-development仅追加可选文案入口。

copy-polish不含私人中转站、账号、固定模型或主机诊断目录。live必须提供包外配置，明确Gemini兼容origin、model、key环境变量及私有诊断根；未配置拒绝，不默认外发。离线原始响应重评与显式留源都保全原失败；其他内容仍须原生逐项审阅，不能用fixture或三项决定伪装整稿成功。真实报告/调用记录不随包分发。

上下文工具只使用标准库与临时事件合同。安装默认预览，--apply和具体home由接收方选择，既有钩子保全，源码/策略变化重新审查，不绕过信任。没有在接收方真实客户端激活、启动服务或运行模型。

升级时先保全2.2.0外部home和包外私有配置，使用prepare_home.py创建全新的2.3.0 home；已有目录拒绝覆盖。指向新home前检查所选工具，provider与客户端配置另行显式接入。旧home仍可用作包文件回退，新版私有证据使用相应版本reader，不把新mode改称旧live。预算钩子更新会改变源码摘要，需重新审查；要恢复旧钩子，先按新home原生uninstall清理自有条目，再用保全的旧版本install预览，不能覆盖其他owner的hooks。

接收方需自行验证实际服务与客户端覆盖。本版本维护验证不发live/API/付费请求，不安装依赖，不新增Docling转换或运行GPU。Docling本机依赖守卫已重新实证通过，但私有共享环境仍未成为独立公开接收配置，因此不列入本次19项新增能力。动画ZIP权限不明、模型/视频与其他源待资格审核的内容也不随包加入。
